# Decisiones técnicas

Este directorio registra decisiones técnicas aprobadas que afectan a la arquitectura, el desarrollo o la operación de REICHEL FLOW.

## Estado

No hay decisiones de stack aprobadas. Las propuestas y comparaciones abiertas pertenecen a su issue o brief; solo una resolución aprobada se consolida aquí.

## Formato recomendado

Cada decisión debe incluir:

- título, fecha y estado (`propuesta`, `aprobada`, `sustituida` o `rechazada`);
- contexto y problema;
- criterios y restricciones;
- alternativas comparadas;
- decisión y responsable de aprobación;
- consecuencias, riesgos y estrategia de reversión;
- enlaces al issue, brief y decisión funcional relacionada.

Usa un archivo independiente con un nombre estable, por ejemplo `0001-titulo-breve.md`. Una decisión nueva no debe reescribir silenciosamente la historia: si reemplaza otra, ambas deben enlazarse y reflejar su estado.

Este registro no sustituye el Blueprint ni el registro funcional de Drive.
