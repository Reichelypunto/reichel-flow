# Desarrollo

REICHEL FLOW todavía no ha iniciado el desarrollo del producto. Este directorio define cómo se trabajará cuando exista un issue o brief aprobado.

## Reglas actuales

- No hay framework, lenguaje ni stack seleccionados.
- No hay configuración de Cloudflare aprobada.
- No deben añadirse dependencias, boilerplate o estructuras de frontend/backend por anticipado.
- Cada cambio debe ser trazable a un issue o brief.
- Código, pruebas y documentación técnica evolucionan juntos.
- Las decisiones técnicas relevantes se registran en `docs/decisions/` tras su aprobación.

El proceso obligatorio se describe en [workflow.md](workflow.md).
